# LIA Taxi — Front-end concept prototype

A responsive English-language website concept for a taxi company serving Greater Montreal.

## Files
- `index.html` — semantic page structure, SEO starter metadata, LocalBusiness/TaxiService JSON-LD
- `styles.css` — responsive visual system and layouts
- `script.js` — mobile navigation, one-way/return tabs, swap locations, client-side form validation and demo feedback

## Run locally
Open `index.html` in a browser. Internet access is needed for the Google Fonts and Unsplash image URLs.

## Before production
1. Replace the placeholder phone, email, domain, and company details with verified business information.
2. Confirm actual service areas, vehicle availability, operating hours, fare policy and driver eligibility.
3. Connect booking/contact/newsletter forms to a backend or approved booking platform. They currently do not transmit or store data.
4. Add a real booking provider/map autocomplete if required.
5. Create original service-area pages and useful blog articles; don't publish duplicate/thin pages solely for keywords.
6. Add a French-Canadian version (`fr-CA`), translated by a qualified reviewer, with hreflang/canonical handling.
7. Add privacy policy, terms, cookie/analytics consent if applicable, accessibility checks, performance testing, sitemap.xml and robots.txt.
8. Replace illustrative image URLs with licensed/owned optimized local images.
9. The structured data is a starter template; validate it and ensure every claim matches the real business.
